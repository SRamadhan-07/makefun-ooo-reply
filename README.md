A Python program — standard library only, no network — that writes one line to /output/entry.txt: a funny out-of-office reply from an agent offline for scheduled daydreaming, which has read, ranked and gently judged your email in your absence. The line is 117 characters, inside this competition's gate of 1 to 160 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
